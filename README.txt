CSS-only update

styles.css?v=2 in index.html.

Script-only update
Replace only index.html and script.js. Advance the script version in
index.html. The script filename stays the same.

Replace the changed SVG in images/ and index.html. Advance the version
on every reference to that SVG in index.html. The motion SVGs in this
package play once. If importing a source loop, change its CSS animation
iteration count to one before uploading.
